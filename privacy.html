Privacy Policy

Last updated: October 17, 2026

This policy covers the Pip & Momo Uploader (the "API Client"), a private tool that publishes videos to the Pip & Momo YouTube channel, and this website.

Use of YouTube API Services

The Pip & Momo Uploader uses the YouTube API Services. Its only function is to upload the channel's own original videos, with their titles, descriptions, tags, and privacy, made-for-kids, and AI-content settings, to the channel owner's YouTube account. By using the Pip & Momo Uploader you are also bound by the YouTube Terms of Service. YouTube's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

Who uses the API Client

Only the owner of the Pip & Momo channel uses the API Client, by signing in with their own Google account. It is not available to the public and does not let anyone else sign in.

Information accessed, collected, stored, and shared

  • Accessed: with the channel owner's permission, the API Client requests the youtube.upload permission only, which lets it upload videos to the owner's channel. It does not read viewer data, comments, subscribers, analytics, or any other account data.
  • Stored: an OAuth access credential (a refresh token) for the owner's own account, kept as an encrypted secret in the owner's private automation environment, plus a log of the channel's own uploads (title, topic, date, and video ID).
  • Used: solely to upload the channel's videos.
  • Shared: nothing is sold or shared with third parties. Videos and their metadata are sent to YouTube as part of uploading.

Viewers and children

The channel's videos are made for kids and are watched on YouTube, not on this website. Neither this website nor the API Client collects personal information from viewers, including children. This website uses no cookies, analytics, or tracking.

Revoking access and deleting data

The account owner can revoke the API Client's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request, the stored credential is deleted within 7 days. Uploaded videos remain on YouTube until deleted in YouTube Studio.

Changes and contact

If this policy changes, the updated version will be posted on this page with a new date. Questions or deletion requests: open an issue on this site's GitHub page.
